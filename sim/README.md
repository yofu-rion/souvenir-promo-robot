# SRR モーションラボ（簡易シミュレータ）

自己推薦ロボットの「回転・昇降・傾き」で感情を表現し、実機の速度・加速度上限で再現できるかを確かめるブラウザ用シミュレータ。

## 起動

```sh
npm run sim        # http://localhost:8000 を開く
npm test           # モーション計算のテスト
```

ES モジュールと `presets.json` を読み込むため、`index.html` を直接ファイルとして開くのではなく、ローカルサーバー経由で開く。

## できること

- **感情プリセット**：待機・呼び込み・喜び・お礼・おねだり・驚き・照れ・悲しみ・すねる
- **感情マップから生成**：快不快（Valence）× 覚醒度（Arousal）の平面をクリックすると、その感情の動きを自動生成する
  - 快：高い位置・上向き・弾む
  - 不快：低い位置・うつむく・背を向ける
  - 高覚醒：速く大きく
  - 低覚醒：ゆっくり小さく
  - 不快かつ高覚醒：小刻みで硬い動き
- **センサーイベント**：接近・立ち止まり・手に取る・棚に戻す・立ち去る、を押すと対応する感情を再生する（対応表は `presets.json` の `events`）
- **説明文から長尺モーション**：おみやげの説明文（1 行 1 文）から、約 1 分の動きを作って読み上げと同期再生する
  - 文ごとにキーワードから感情を推定する（例:「人気」「限定」→ 喜び、「職人」「伝統」→ お礼、「ぜひ」「お土産に」→ おねだり、「実は」→ 驚き）
  - 文頭に `[照れ]` や `[V0.5 A-0.2]` を付けると感情を指定できる
  - 各文は「文頭のしぐさ（プリセット）＋話している間の控えめな動き」で構成する。文の長さは話す速さ（字/秒）から見積もる
  - 読み上げが見積もりより長引いた場合は、次の文の手前で動きを待たせて同期を保つ
  - 文の一覧をクリックすると、その文から再生できる。サンプルは `scripts/sample-souvenir.txt`
- **実機の再現性チェック**：指令値（破線）と、速度・加速度上限つきの応答（実線）をタイムラインに重ねて表示する。上限超えや追従遅れがあれば警告する
- **軸の設定**：可動域・最大速度・最大加速度を実機に合わせて変更できる。傾き軸は拡張軸で、既定では無効
- **入出力**：
  - モーション JSON を編集して再生できる
  - 実機用 CSV（50Hz、上限処理後の値）をコピーできる
  - セリフを読み上げられる（Web Speech API）

## ファイル

| ファイル | 内容 |
| --- | --- |
| `motion-core.js` | 補間・アクチュエータ模擬・感情からの生成・検証・CSV 出力。DOM 非依存で、Node からも使える |
| `presets.json` | 感情プリセットとセンサーイベントの対応表 |
| `index.html` | 3D ビュー（Three.js r128）、タイムライン、操作 UI |
| `test/motion-core.test.mjs` | `node --test` 用テスト |

## モーション形式

```json
{
  "id": "joy",
  "name": "喜び",
  "valence": 0.9,
  "arousal": 0.8,
  "duration": 2.6,
  "loop": false,
  "tracks": {
    "yaw":   [[0, 0], [0.35, 25], [0.7, -25]],
    "lift":  [[0, 15], [0.25, 34]],
    "pitch": [[0, 0], [0.2, 15]]
  },
  "speech": "やったー！選んでくれてありがとう！",
  "voice": { "rate": 1.2, "pitch": 1.4 }
}
```

### tracks（各軸のキーフレーム）

キーフレームは `[時刻(秒), 値, イージング]` の形で書く。各軸の値の単位は次のとおり。

| 軸 | 内容 | 単位 | 向き |
| --- | --- | --- | --- |
| `yaw` | 回転 | 度 | — |
| `lift` | 昇降 | mm | — |
| `pitch` | 傾き | 度 | ＋が上向き |

イージングは `linear` / `inOut`（既定）/ `in` / `out` / `step` のいずれか。

### 実機の軸設定

既定の軸設定（`DEFAULT_AXES`）は仮の値なので、実機の機構に合わせて `motion-core.js` の値を変更する。
