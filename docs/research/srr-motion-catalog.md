# 本家 SRR のモーションカタログ

サイバーエージェントの自己推薦ロボット（SRR）の振る舞いを、公開されている論文・報道の記述から再構成したもの。シミュレータの `sim/presets.json` と、`sim/motion-core.js` の `generateDance` に実装している。

## 一連の流れ（シミュレータの「通しで再生」）

```
接近 ─▶ 呼びかけ ─▶ 立ち止まり ─▶ お礼 → 手に取って
                                      │
                       手に取る ─▶ ダンス（拍に合わせる） → 連れて帰って
                       棚に戻す ─▶ 悲しみ
                       立ち去る ─▶ 待機
```

Playful Recommendation では、呼びかけ → 手に取ってのお願い → 手に取られた後に音楽に合わせてダンス → 最後に連れて帰ってのお願い、という順序だと紹介されている。きっかけと振る舞いの対応は `presets.json` の `events` で変えられる。

## ダンスの生成（`generateDance`）

報道では「音楽に合わせて回転・上下」とだけあり、振付は公開されていない。そこで次の 3 種類を用意し、どのテンポ（60〜180 BPM）でも実機の速度・加速度上限に収まるよう振れ幅を自動で抑えている。

| スタイル | 回転 | 昇降 | 傾き |
| --- | --- | --- | --- |
| ノリノリ | 拍ごとに左右へ振る | 拍で沈み、裏拍で跳ねる | 左右に揺れる |
| くるくる | 小節の最後の拍で 1 段回る（±2 段の往復） | 毎拍小さく跳ねる | 跳ねに合わせて上を向く |
| ゆらゆら | 2 拍で左右に揺れる | 1 小節かけて上下に波打つ | ゆっくり揺れる |

どのスタイルも、最後の拍の次に決めポーズ（高い位置で上を向く）を 1 拍保ち、中立の姿勢に戻る。

## 動画が手に入ったら

手元で動画をダウンロードしてリポジトリに置く（例：`docs/research/video/`。容量が大きい場合はコミットしない）。次のコマンドで、時刻入りのコマ画像と一覧画像を作る。

```sh
tools/video-frames.sh 動画.mp4 video-frames 5   # 5 コマ/秒
```

一覧画像（`video-frames/sheet-*.jpg`）を見て、次の点を確かめ、`presets.json` のキーフレームを直す。

- 回転角
- 昇降量
- 傾きの有無
- 各動作の時刻
- セリフと動きのタイミング
