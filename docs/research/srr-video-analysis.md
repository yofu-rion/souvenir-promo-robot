## 説明動作への反映

| 前 | 後 |
| --- | --- |
| 客側を向いたまま、小さくうなずく（約 5 mm） | 文の頭で向き（客側の 25°・45°・65°）と高さ（感情）を素早く変え、話している間は止まる。お願い・お礼・呼びかけは正対 |
| 読点はいつもうなずく | うなずきと向き変え（15°）を交互に |
| 見た目の話も同じ動き | 「回し」「形」「再現」「見た目」などの文では、左右 35° に回して横を見せる |
| ダンスなし | 「楽しいよ！」の後に約 9 秒のダンス（120 BPM、自作の音楽）。右へ振る → 沈む → 跳ねる → 左へ振る…を拍に乗せ、決めの和音で高い位置に着く |
| 呼びかけは跳ねるだけ | 大きく振り向いてから正対して、大きく 2 回跳ねる |

要件（昇降とヨーを同時に動かさない、テーブル 60°/s 以下）は守る。キレを出すため、ヨーの加速度を 240 → 360°/s²、昇降を 240 → 400°/s² に上げた。`srr sync-check 1` で、どの動きも狙った句末・拍の −33〜−6 ms に着くことを確かめた。

## 本家との違い（残っている課題）

- 本家は 60°/s を超える速さで回っているように見える。こちらは要件の 60°/s を守るため、ダンスの振りは 2 小節に 1 回程度になる。
- 本家は複数の商品でそろって踊る。こちらは 1 基構成のため 1 つだけ。2 基構成にしたら、掛け合いとそろったダンスを入れたい。
- 本家の動きの細かな振付（角度・拍）は、動画の解像度とカメラの揺れのため、数値では取れていない（位相相関で追ったが、商品が回って見え方が変わるため当てにならなかった）。
