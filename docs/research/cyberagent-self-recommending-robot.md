# 調査メモ: サイバーエージェント「自己推薦ロボット」

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| 名称 | 自己推薦ロボット（Self-Recommending Robot / Agent） |
| 開発 | 株式会社サイバーエージェント AI Lab ＋ 大阪大学大学院基礎工学研究科 石黒浩研究室（共同研究講座） |
| 主な研究者 | 岩本拓也（AI Lab）、馬場惇、石黒浩 ほか |
| 定義 | 商品に「動く・話しかける」などの**生命感**を付与し、**商品自らが自分の機能や利便性を推薦しているように**振る舞うロボット |
| 本記事の実証 | 近商ストア「ハーベスLINKS UMEDA店」（大阪市北区）、2023年4月24日〜7月末ごろ |
| 本記事の検証目的 | 商品を入れ替えながら長期間推薦を続けたときに、効果が**持続するか（飽きられないか）**の検証 |
| その後 | 2023年夏にトライアル販売を予定、2024年度にも本格販売の方針と報道 |

## 2. 動作・インタラクション

1. 陳列された商品が、**通りかかった来店客に声をかける**（呼び込み）。
2. 客が**立ち止まると反応**して、商品自身が自分の特徴・機能・利便性をアピールする。
3. 商品を載せた台が回転・昇降して**ダンス**し、最後に「うちに連れてってあげて」のような**おねだり**（購入を促すセリフ）をする。

ポイントは、キャラクター型ロボットが商品を紹介するのではなく、**商品そのものが話し手（エージェント）になる**こと。

## 3. ハードウェア／システム構成（報道から分かる範囲）

- **スピーカー付き小型回転昇降台（ステージ）**：上に商品を載せると、商品が回ったり上下したりして「踊る」。
- **コンセント一つで動作**、**プログラミング不要**で商品をロボット化できるシステムとして開発（2023年9月報道）。
- **センサー：重量センサー＋AIカメラ**（2022年9月 サッポロドラッグストアー実証の報道より）。
  - AIカメラ：客が**目の前に立ち止まった**ことを検知 → 動きながらお礼を言う、などの振る舞い。
  - 重量センサー：商品が**手に取られた／戻された**ことを検知 → 手に取るとお礼やダンス、戻すと悲しむ。
  - センサー入力に応じた振る舞いを自由に設計できる、とされている。具体的な型番・設置位置は非公開。図3の筐体前面の窓がカメラ等の窓である可能性はあるが未確認。
- 発話は商品ごとの推薦セリフ（商品が一人称で話す形式）。

### 3.1 JCSS2024 論文（図3「SRR動作システム」）から分かること

- 外観：**白い箱型の筐体**の上面に**円盤（ターンテーブル状）**があり、その上に**斜めに立った板（商品を立て掛ける受け台）**が付いている。筐体前面には小さな長方形の開口が1つある（用途は記載なし。センサー窓や端子の可能性）。
- 論文中の記述は「システム上部の動作部分に商品を設置することで、設定した動きと同時に音声を再生する」のみ。
- 実験（印象評価）で使った動作は**上下運動**（約3秒）。音声は合成音声ソフト **Voicepeak の女性声**で「(商品カテゴリ名)です。買って下さい」。
- **軸数は論文にも明記されていない**。報道の「回転昇降台」という表現と、図3の円盤＋上下運動から、**回転（縦軸まわり）＋昇降の2軸**と推定するのが最も自然。受け台の傾きが可動かどうかは判別できない。

### 3.2 動きの作り方（公開情報から分かる範囲）

- **音楽に合わせたダンス**：回転と上下動を音楽に合わせて行い、注意を引いて足を止めさせ、最後に「手に取ってほしいな」とおねだりする（ニュースイッチ 2023）。
- **商品に依存しない定型パターン**：Playful Recommendation（RA-L 2022）は、商品ごとに説明を作るのではなく、快感情を刺激する共通の振る舞いで推薦する。商品を入れ替えても使え、店舗の要望に素早く対応できることが狙い。実証ではダンスとセリフを統一して検証した。運用時は商品ごとに変えられる可能性がある、とされる。
- **センサー起点のイベント駆動**：立ち止まり（AIカメラ）、手に取る／戻す（重量センサー）に応じて、お礼・ダンス・悲しむなどの振る舞いを切り替える。
- **プログラミング不要**：店舗側はステージに商品を載せて電源を入れるだけ。動きの作成ツールや内部の表現形式（キーフレームか、音楽からの自動生成か）は公開されていない。
- **声が最も効く**：感情認識への影響は聴覚情報が 68% で最大（感性工学会論文誌 2023）。動きよりも声のトーン設計の比重が大きい。

## 4. これまでの成果（数値）

| 実験 | 結果 |
| --- | --- |
| 過去の複数実証（2021年〜、スーパー・ドラッグストア・コンビニ・大型雑貨店など） | 立ち止まり率 **2.14倍**、販売率 **6.67倍** の事例 |
| ハロウィーン向けカボチャ容器入りあめ（2022年） | ダンス＋おねだりで、通常の商品説明に比べ販売数 **1.42倍**。立ち止まり確率 +16%、購入確率 +42%。ロボット化しない通常条件比で通行人あたり購入率 **約6倍** |
| 商業施設での長期実証（ハーベス、20商品・約5カ月） | **5カ月経っても販促効果が持続**。多い商品では **2〜3倍** 売れた |
| 大型雑貨店（Playful Recommendation, IEEE RA-L 2022） | 商品説明の代わりに快感情を刺激する推薦で販売数 **6倍以上** |
| ドラッグストア | 販売数 **2.37倍**、滞在時間 **1.22倍** |
| 定常的に販売されている商品（HRI 2022） | 販売数が**増加しにくい**可能性 |

## 5. 関連する研究・実証

- **HAI 2021**「The Effectiveness of Self-Recommending Agents in Advancing Purchase Behavior Steps in Retail Marketing」：ロボットエージェントが商品を紹介する場合と比較し、自己推薦エージェントの方が多くの客にリーチし、商品内容の記憶も多かった（Outstanding Research Award）。
- **HRI 2022**「Pick-me-up Strategy for a Self-recommendation Agent」：コンビニでのパイロットフィールド実験。「私を手に取って」という戦略の検証。
- **グリーンローソン（2023）**：2種類のロボットによる分業型推薦の実証。
- **PLAZA NEWSSTAND（2023年10月〜）**：美容・ヘルスケアという新カテゴリ・新店舗形態で、販促効果の**及ぶ範囲**を調査。
- **日本感性工学会論文誌 Vol.22 No.2（2023）**：SRRの視覚・言語・聴覚情報が矛盾する場合、感情認識への影響度は視覚 15.2%、言語 16.8%、**聴覚 68.0%**。**声のトーンが最も効く**。
- **JCSS2024 P-1-29**「自己推薦ロボットが推薦商品の印象形成に与える影響の検討」（岩本拓也・岡藤勇希）：下記 5.1 参照。

### 5.1 JCSS2024 P-1-29 の要点

- 方法：実在する8商品（飲食経験ありの身近な商品4種＝ポテトチップス、チョコ菓子、飲料など／経験なしのPB商品4種）。静止写真と約3秒の動作動画を提示し、7項目を5段階評価。オンライン調査、有効回答80名。2要因ANOVA。
- 動作させると「**高価な**」「**個性的な**」「**新しい**」「**可愛らしい**」が有意に上昇、「**美味しそう**」が有意に低下（生命感を付与すると食べることへの抵抗感が生じる可能性）。
- 飲食経験**あり**の商品：「美味しそう」「飽きなさそう」「好き」が**低下**。
- 飲食経験**なし**の商品：「高価な」「個性的な」「好き」「可愛らしい」が**上昇**し、有意な低下はなし。
- 結論：SRRは**新商品・認知度の低い商品**に向く。定番の食品では逆効果になり得るため、商品特性と消費者の経験を考慮した運用が必要。

## 6. 設計上の示唆（なぜ効くのか）

- **飽きにくい**：従来のコミュニケーションロボットはキャラクターに慣れると効果が落ちる。商品自体がロボットになれば、**商品を入れ替えるだけで新鮮さを保てる**。
- **購買プロセスの段階を進める**：注意喚起（動き・声）→ 立ち止まり → 情報提供 → 購買（おねだり）の各ステップを一体で押し上げる。
- **遊び心**：機能説明よりも、ダンスやおねだりといった遊び心ある自己推薦の方が購入につながりやすい。
- **導入の手軽さ**：電源だけ・プログラミング不要という運用面の簡単さが、店舗導入の鍵。
- **向き不向き**：新商品・初めて見る商品では印象が上がるが、食べ慣れた食品では「美味しそう」「好き」が下がる。

## 7. 本プロジェクト（souvenir-promo-robot）への落とし込み

「自己推薦ロボット」を模倣し、**お土産販売向け**に拡張することを想定した整理。

### 7.1 模倣する最小構成（MVP）

- **回転＋昇降の2軸ステージ**（サーボ／ステッピングモーター）。本家と同様に、円盤の上に商品を立て掛ける受け台を載せる形
- スピーカー
- 本家と同じ**カメラ（人の立ち止まり検知）＋重量センサー（ロードセル＋HX711 等で手に取り検知）**。カメラの代わりに ToF 距離センサーで簡易化も可
- 制御ボード（例：Raspberry Pi / ESP32）
- 状態遷移：`待機 → 呼び込み（接近検知） → 自己紹介（立ち止まり検知） → ダンス → おねだり → 待機`
- 商品ごとのセリフ・動きのプリセット（設定ファイルで差し替え、プログラミング不要を目指す）

### 7.2 お土産販売ならではの拡張案

- **多言語対応**：インバウンド観光客向けに、カメラ／マイクによる言語推定や言語選択ボタンで日英中韓などを切り替え。
- **ご当地ストーリー**：商品の由来・産地・名物エピソードを商品自身が語る（お土産は「物語」で選ばれやすい）。
- **生成AIによる対話**：定型セリフに加え、LLM＋音声認識・合成で「日持ちは？」「アレルギーは？」などの質問に商品自身が答える。
- **複数商品の掛け合い**：隣り合う商品同士が会話・競い合う演出（分業型推薦の応用）。
- **購入導線**：QRコード表示でEC・配送・クーポンへ誘導。
- **効果測定**：接近数・立ち止まり数・対話数をログ化し、POSデータと突き合わせて販促効果を可視化。
- **飽き対策**：時間帯・季節・天気・在庫に応じてセリフや動きを自動で変える。
- **お土産との相性**：観光客にとってご当地のお土産は「飲食経験なし」の商品が多く、SRRで印象が上がりやすい（JCSS2024）。一方、食品で「美味しそう」が下がる点には対策が要る。動きを控えめにする、試食や商品写真と組み合わせる、味を語る発話を増やすなど。
- **声の設計を最優先**：感情認識は聴覚情報の影響が68%と大きいため、声質・トーンへの投資が効果的。
- **表現力の拡張**：3軸目（チルト）を追加し、お辞儀や首をかしげる動きを可能にする（本家からの拡張）。
