# 説明動作の動き方（話し手の頭部動作の研究から）

台本で説明するときの実機の動き（`robot/srr/explain.py`）を、話し手の頭部動作の研究に合わせて決めた。調査日: 2026-10-19。

## 研究から分かったこと

| 知見 | 出典 |
| --- | --- |
| 話し手は話しながらよくうなずく。相づちや同意だけでなく、強い句境界の最後の音節でうなずく | [Ishi ほか, AVSP 2008](https://www.isca-archive.org/avsp_2008/ishi08_avsp.html)、[劉・石井・石黒, JSAI 2011](https://www.ai-gakkai.or.jp/jsai2011/webprogram/2011/pdf/421.pdf) |
| 考えている、次の発話を準備している、といった弱い句境界では首傾げが多い。首傾げは約 0.4 秒で 15° 傾け、次の句が終わるまでに戻す | 劉・石井・石黒, JSAI 2011 |
| 句境界の規則で作ったうなずき・首傾げは、人の動きをそのまま写すより自然と評価された | 劉・石井・石黒, JSAI 2011 |
| 口のないロボットは、発話区間に顔を軽く（約 3°）上げると、話しているように見え、自然さの評価が上がる（Robovie R2: 39.9 → 49.9 点） | 劉・石井・石黒, JSAI 2011 |
| 日本語では、声の高さと頭の動きの相関は 0.22〜0.30 と低い。声の高さから直接動きを作るより、句境界の規則のほうが向く | 劉・石井・石黒, JSAI 2011 |
| 声が小さいときは頭はほとんど動かない。高い声で上を向き、低い声で前や下を向く。動きは 5° 未満と小さい | [Sakai ほか, Frontiers in Robotics and AI 2017](https://www.frontiersin.org/articles/10.3389/frobt.2017.00049/full) |
| 動いている商品は、食べ慣れた食品だと「美味しそう」が下がる。動きは控えめにする | JCSS2024 P-1-29（`docs/research/cyberagent-self-recommending-robot.md`） |

## 2 軸（回転・昇降）への置き換え

首のうなずきは昇降で、顔の向きはヨーで表す。昇降とヨーは同時には動かさない（要件）。客側を向いたままの昇降はしてよい（ヨーが止まっている間だけ）。

| 動き | 実機での動き | いつ |
| --- | --- | --- |
| 発話のサイン | 少し上がる（行程の 6%、約 3.6°） | 声の始まり |
| 文末のうなずき | 少し沈んで戻る（行程の 9〜13%） | 文末の句の終わりの 0.3 秒前に始める |
| 読点のうなずき | 文末より浅く（行程の 5〜7%） | 息継ぎのある句の終わり |
| 首傾げの代わり | 向きを 7° 変えて、次の句の終わりまでに戻す | 4.5 秒以上の文だけ、息継ぎのない句境界で 1 回 |
| 向き | 客側を向いたまま止まる。左右に揺らし続けない | 向き直りは文と文の間だけ |
| 感情 | 快いほど高く、覚醒度が高いほどうなずきが深く速い。不快な文は低く、小さく遅く、少しそっぽを向く | 文ごと |
| しぐさ | 呼びかけは話す前に 2 回跳ねる。お礼は文末で深くお辞儀。喜びは文末で弾む | 文ごと |

句の区切りの時刻は、VOICEVOX の `audio_query` が返すアクセント句ごとの長さと息継ぎ（`pause_mora`）から出す（`tools/make-voice.py --plan` が `01.json` などに書く）。

## 未確認

- うなずきの深さ（行程の約 10%、昇降で約 1.5 mm）が、店頭の距離から見て分かるか。
