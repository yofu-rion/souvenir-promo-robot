# ネジチョコ（北九州）商品メモ

説明文 `sim/scripts/neji-choco.txt` の根拠。公式サイトはこの環境から直接開けなかったため、検索結果の抜粋をもとにまとめた。店頭で使う前に販売元へ確認すること。

| 項目 | 内容 | 出典 |
| --- | --- | --- |
| 製造・販売 | 開発はオーエーセンター（OAセンター）株式会社。工場の名前は「ネジチョコラボラトリー」。旅行メディアでは、北九州の洋菓子店「グランダジュール」が製造販売するとも紹介されている（公式 BASE ショップの URL も grandazur） | 公式サイト、経産省ジャーナル、たびらい、OAセンター |
| 誕生の経緯 | 「明治日本の産業革命遺産」の世界遺産登録（2015年、八幡製鉄所を含む）を背景に、鉄の街・北九州のお土産として考案された | 公式 ABOUT、経産省ジャーナル |
| 発売 | 2016年2月のバレンタインデー | 経産省ジャーナル |
| 特徴 | ボルトとナットの形で、実際に締めたり外したりできる。3D プリンターで精巧な形を再現 | 公式サイト |
| 工場 | 2020年に生産を大幅に自動化した新工場「ネジチョコラボラトリー」が稼働 | 公式 LABORATORY、経産省ジャーナル |
| 味 | 定番のスイート（プレーン）、鉄錆をイメージしたココアをまぶしたココア味、ホワイト、博多あまおう、門司港バナナ など | 公式 ITEM、たびらい |
| 入数 | 5個入り、15個入り | 公式 ITEM |
| 製造終了 | アソート、ストロベリー、抹茶 | 公式 ITEM |
| 関連商品 | 日本製鉄缶ネジチョコ（8個入り）。九州工業大学とのコラボ商品（2024年11月〜） | 公式 ITEM、九州工業大学 |
| 保存 | 直射日光・高温多湿を避け、25℃以下で保存 | 販売ページ |
