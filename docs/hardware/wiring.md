# 配線（2基構成前提）

端子台・電源は 2 基構成を前提に割り当てる。1 基目だけで立ち上げるときは、「2 基目」と書いた線を空けておき、2 基目を足すときにつなぐ。ピン割り当て・電源仕様は要件ドキュメント「[商品自己推薦ロボット システム要件（実機立ち上げ用）](https://claude.ai/artifact/F5UaW2FXtHF9ZjsqB2cjcc)」が正。

## 通電前に

降圧コンバーター（WMYCONGCONG、出力可変）は、何もつながずに 12 V を入れ、テスターで出力を合わせてから負荷をつなぐ。

- 降圧 A（サーボ用）：6.0 V
- 降圧 B（Pi・アンプ用）：5.15 V（USB-C ケーブルでの電圧降下を見込んで 5.2 V まで可）

## 端子台（春日電機 T1006 ×2）

各極は上下のねじがつながっている（1 極に 4 枚まで）。上を入力、下を出力とし、ねじ 1 本に Y 形端子（ニチフ 1.25Y-3.5）を 2 枚まで重ねる。電圧の極の隣は必ず GND にし、端子が隣に触れても高い電圧が別の系統に回らないようにする。

### 端子台 A（12 V・サーボ電源）

| 極 | 中身 | 上 | 下 |
| --- | --- | --- | --- |
| 1 | 12 V | ヒューズから | 降圧 A の IN+、降圧 B の IN+ |
| 2 | GND | DC ジャックの GND、A4 へのジャンパー | 降圧 A の IN−、端子台 B の 3 極へ |
| 3 | 6.0 V | 降圧 A の OUT+ | サーボ分配基板 1 の＋、分配基板 2 の＋（2 基目） |
| 4 | GND | A2 からのジャンパー、降圧 A の OUT− | 分配基板 1 の GND、分配基板 2 の GND（2 基目） |
| 5 | 空き | | |
| 6 | 空き | | |

### 端子台 B（Pi・アンプ電源）

| 極 | 中身 | 上 | 下 |
| --- | --- | --- | --- |
| 1 | 5.15 V | 降圧 B の OUT+ | USB-C の赤、アンプの VIN |
| 2 | GND | 降圧 B の OUT−、B3 へのジャンパー | USB-C の黒、アンプの GND |
| 3 | GND | B2 からのジャンパー、端子台 A の 2 極から | 降圧 B の IN−、空き |
| 4〜6 | 空き（予備） | | |

ジャンパーと端子台間の線は短い 18AWG の両端に Y 形端子。GND はこれで全系統つながる。

## 線とコネクタ

| 区間 | 線 | つなぎ方 |
| --- | --- | --- |
| DC ジャック → スイッチ RK2-13 → ヒューズ → A1 | 18AWG | ジャックはハンダ付け＋熱収縮。スイッチは＋側だけ通す（平型なら平型端子メス）。端子台側は Y 形端子 |
| 端子台 ↔ 降圧コンバーター | 18AWG | 端子台側は Y 形端子、コンバーター側はねじ端子に直接 |
| A3・A4 → サーボ分配基板（基ごとに 1 枚） | 18AWG | 基板側はハンダ付け |
| 分配基板 → サーボ | 付属線 | 3 ピンのオスのピンヘッダ（2.54 mm）に付属コネクタを挿す。並びは GND（茶）・＋（赤）・信号（橙） |
| B1・B2 → Pi 5 | USB-C 2 芯 22AWG | 赤を B1、黒を B2 |
| B1・B2 → アンプ MAX98357A | 26AWG | VIN・GND |
| Pi → 分配基板・HX711・アンプの信号 | 26AWG | Pi 側は 2.54 mm メスコンタクト |
| ロードセル SC133 → HX711 | ロードセルの線 | HX711 の E+/E−/A−/A+ にハンダ付け |

## サーボ分配基板（基ごとに 1 枚）

ユニバーサル基板に GND 行と＋6.0 V 行を通し、3 ピンのピンヘッダを 2 つ（昇降・ヨー）立てる。2200 µF（16 V）を 2 行の間に付ける（帯の側を GND）。信号ピンは 26AWG で Pi へ、GND 行には Pi の GND ピンからも 26AWG を 1 本つなぐ。

| | 昇降の信号 | ヨーの信号 | GND |
| --- | --- | --- | --- |
| 1 基目 | ピン 32（GPIO12） | ピン 36（GPIO16） | ピン 9 |
| 2 基目 | ピン 33（GPIO13） | ピン 16（GPIO23） | ピン 39 |

## HX711（SparkFun Load Cell Amp ×2、1 枚のユニバーサル基板）

2 枚の HX711 を 1 枚の基板に載せ、基板の裏で 3.3 V・CLK・GND を共通にする。Pi へ出す線は 5 本。

| HX711 のピン | 基板の上でのつなぎ方 | Pi のピン |
| --- | --- | --- |
| VDD・VCC | 1 枚ごとに 2 本をつなぎ、2 枚分を 3.3 V の行にまとめる | 1（3.3 V）。5 V にしない |
| CLK | 2 枚分をまとめる | 29（GPIO5） |
| GND | 2 枚分をまとめる | 6 |
| DAT（1 基目） | そのまま | 31（GPIO6） |
| DAT（2 基目） | そのまま | 37（GPIO26） |

| HX711 のピン | ロードセル SC133 |
| --- | --- |
| RED / BLK / WHT / GRN | 赤（E+）/ 黒（E−）/ 白（A−）/ 緑（A+） |
| YLW | つながない（シールド用。SC133 は 4 本） |

ロードセルの線は mV 単位の信号なので、4 本を撚り合わせて短くする。2 基目のロードセルまで遠い場合も 50 cm 程度までに収める。

## 音声アンプの信号

| アンプのピン | Pi のピン |
| --- | --- |
| BCLK / LRC / DIN | 12（GPIO18）/ 35（GPIO19）/ 40（GPIO21） |
| Vin / GND | 端子台 B1 / B2 |
| GAIN | つながない（基板の Gain ジャンパーで 3 / 9 / 15 dB、既定 9 dB） |

## 音声アンプ（MAX98357A ステレオ、1 枚）

1 枚で左右 2 チャンネルを鳴らす。Pi では `hifiberry-dac` の overlay（`I2S_OVERLAY=hifiberry-dac tools/setup-pi.sh`）で音声デバイス `sndrpihifiberry` になり、`config.yaml` の `audio.device` は `plughw:CARD=sndrpihifiberry,DEV=0`。BCLK はピン 12（縁側の列の 6 本目）。ずれると何も鳴らない。L 出力を 1 基目、R 出力を 2 基目のスピーカーにつなぐ（`config.yaml` の `channel` と同じ）。1 基目だけのうちは L だけつなぐ。

- 出力は BTL（+ と − の両方が駆動される）。スピーカーの − を GND につながない、L と R の出力どうしをつながない。
- 確認：`speaker-test -c 2 -t wav` で「Front Left」が 1 基目、「Front Right」が 2 基目のスピーカーから鳴る。

## 電流とヒューズ

- 1 基目だけのうちは 5 A のヒューズを使う。DC ジャック（5.5/2.1）は 3〜5 A 定格のものが多く、10 A ではジャックを守れない。
- 2 基構成にするときは要件どおり 10 A にする。サーボ 4 本が同時に動き出すと 12 V 側で最大 7 A ほど流れる見込みなので、DC ジャックも 8 A 以上の定格のものに替える（手持ちの定格を確認）。
