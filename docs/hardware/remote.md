# M5Stack リモコン（角度調整・動作開始）

M5Stack Core2 / CoreS3 を Bluetooth LE で Pi につなぎ、角度調整と動作の開始・停止に使う。M5Stack は表示とボタンだけで、何を調整しているか・動いているかは Pi（`srr run`）が決める。

## 書き込み（最初の 1 回と、プログラムを変えたとき）

M5Stack を USB-C で Pi につないで書き込む。

```sh
~/.venvs/pio/bin/pio run -d m5remote -e core2 -t upload    # Core2
~/.venvs/pio/bin/pio run -d m5remote -e cores3 -t upload   # CoreS3
```

書き込んだ後は USB を外し、電池で使ってよい。

## 使い方

`srr run`（systemd の `srr-robot`）が動いていれば、Pi が M5Stack（名前 `SRR-Remote`）を探してつなぐ。つながると画面の「Pi と未接続」が消える。

| タブ | ボタン | 動き |
| --- | --- | --- |
| リモコン | ◀ 台本 / 台本 ▶ | 流す台本を選ぶ（`sequence.programs`。画面の 1 行目に番号と名前。動いている途中なら次の説明から） |
| | 入替 | キャラの配置を入れ替える（台本の話者 1 を 2 基目、話者 2 を 1 基目が話す。声の左右も入れ替わる）。もう一度押すと元に戻る。画面の各基の行に、受け持つキャラ（`cast`）が出る |
| | 開始 | 運転を始める（すぐ 1 回目、その後は終わってから設定の「間隔」の秒数ごと） |
| | 1回 | 止めたまま、すぐ 1 サイクルだけ動かす |
| | 停止 | 動いている基を原点へ戻して止める |
| 角度調整 | ◀ 前 / 次 ▶ | 合わせる点を選ぶ。その点へゆっくり動く |
| | −10 / −1 / +1 / +10 | パルス幅を µs 単位で動かす |
| | 保存 | `robot/calibration.yaml` に保存し、すぐ本番の動きに使う |
| 設定 | 音量 − / ＋ / テスト | 全体の音量（0〜200%）。100% が声のファイルそのまま。100% より上は、大きい音だけをリミッターで抑えて割れないようにする。テストで今の音量の声を鳴らす |
| | 動き − / ＋ / 1回 | 説明の動きの大きさ（30〜150%。100% が `sequence.motion_base`）。1回ですぐ試す |
| | 速さ − / ＋ / 停止 | 説明の速さ（50〜130%。100% が `sequence.tempo_base`。最高速度は要件の上限のまま、加速度が変わる） |
| | 間隔 − / ＋ / 開始 | 開始で動かすとき、台本が終わってから次を始めるまでの秒数（0〜600 秒、5 秒ずつ。最初は `sequence.auto_interval_s`）。すぐ効く |
| 手動 | ◀ 前 / 次 ▶ | 動かす軸を選ぶ（1 基目の昇降 → ヨー → 2 基目の昇降 → ヨー） |
| | −10 / −1 / +1 / +10 | 昇降は高さ（0% 最下〜100% 最上）、ヨーは角度（°、＋は客から見て右）。可動範囲の中だけ |
| | 原点 | その基を原点へ戻す |

画面の切り替えは、上のタブのほか、Core2 の本体のボタンでもできる（A：前のタブ、B：リモコン、C：次のタブ）。設定の値と選んだ台本・入替は `~/.local/state/srr-robot/settings.json` に残る。手動タブに入ると運転を止めて原点へ戻ってから始まり、ほかのタブへ移ると全基が原点へ戻る。同じ基の昇降とヨーは同時に動かさない。

### USB ケーブルでつなぐ

Bluetooth がつながりにくいとき（2.4 GHz の Wi-Fi と混信するなど）は、M5Stack を USB-C で Pi につないだまま使える。`config.yaml` を `remote.transport: serial` にし、`remote.serial_port` に M5Stack のシリアル（`/dev/serial/by-id/…`）を書く。同じ JSON を 1 行ずつやりとりし、画面とボタンは Bluetooth のときと同じ。Bluetooth に戻すときは `transport: ble`。

`config.yaml` の `remote.start_paused: true` のときは、起動しても「開始」を押すまで動かない。リモコンを使わないときは `remote.enabled: false` にするか、`srr run --no-remote` で起動する。

## 角度調整

ホーンを付けた後はサーボの端まで回すと機構に当たるので、実際に使う位置で合わせる。1 基あたり 5 点。

| 軸 | 点 | 合わせ方 | 決まる値 |
| --- | --- | --- | --- |
| 昇降 | 下（0°） | パッドが一番下に着く位置 | パルス中心 |
| 昇降 | 上（−60.5°） | 一番上の 1° 手前 | 負側の傾き（端は延長して求める） |
| ヨー | 正面（0°） | テーブルが正面を向く位置 | パルス中心 |
| ヨー | +90°（客側） | 客側へ 90° | 片側の傾き |
| ヨー | −90° | 反対側へ 90° | もう片側の傾き |

- 点を移るときは毎秒 400 µs の速さで動く。昇降を動かす前にヨーを正面へ、ヨーを動かす前に昇降を下へ戻す。
- 1 点で動かせるのは、調整を始めた値から ±250 µs まで。
- 角度調整タブへ移ると、運転を止めて原点へ戻してから始まる。リモコンタブへ戻ると原点へ戻って待機に戻る。保存していない変更があるときは、もう一度押すと破棄して戻る。
- 終了（`systemctl stop`）したときも、原点へ戻してから止まる。
