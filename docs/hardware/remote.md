# M5Stack リモコン（角度調整・動作開始）

M5Stack Core2 / CoreS3 を Bluetooth LE で Pi につなぎ、角度調整と動作の開始・停止に使う。M5Stack は表示とボタンだけで、何を調整しているか・動いているかは Pi（`srr run`）が決める。

## 書き込み（最初の 1 回と、プログラムを変えたとき）

M5Stack を USB-C で Pi につないで書き込む。

```sh
~/.venvs/pio/bin/pio run -d m5remote -e core2 -t upload    # Core2
~/.venvs/pio/bin/pio run -d m5remote -e cores3 -t upload   # CoreS3
```

書き込んだ後は USB を外し、電池で使ってよい。

## 使い方

`srr run`（systemd の `srr-robot`）が動いていれば、Pi が M5Stack（名前 `SRR-Remote`）を探してつなぐ。つながると画面の「Pi と未接続」が消える。

| タブ | ボタン | 動き |
| --- | --- | --- |
| リモコン | 開始 | 運転を始める（すぐ 1 回目、その後は `auto_interval_s` ごと） |
| | 1回 | 止めたまま、すぐ 1 サイクルだけ動かす |
| | 停止 | 動いている基を原点へ戻して止める |
| 角度調整 | ◀ 前 / 次 ▶ | 合わせる点を選ぶ。その点へゆっくり動く |
| | −10 / −1 / +1 / +10 | パルス幅を µs 単位で動かす |
| | 保存 | `robot/calibration.yaml` に保存し、すぐ本番の動きに使う |

`config.yaml` の `remote.start_paused: true` のときは、起動しても「開始」を押すまで動かない。リモコンを使わないときは `remote.enabled: false` にするか、`srr run --no-remote` で起動する。

## 角度調整

ホーンを付けた後はサーボの端まで回すと機構に当たるので、実際に使う位置で合わせる。1 基あたり 5 点。

| 軸 | 点 | 合わせ方 | 決まる値 |
| --- | --- | --- | --- |
| 昇降 | 下（0°） | パッドが一番下に着く位置 | パルス中心 |
| 昇降 | 上（−60.5°） | 一番上の 1° 手前 | 負側の傾き（端は延長して求める） |
| ヨー | 正面（0°） | テーブルが正面を向く位置 | パルス中心 |
| ヨー | +90°（客側） | 客側へ 90° | 片側の傾き |
| ヨー | −90° | 反対側へ 90° | もう片側の傾き |

- 点を移るときは毎秒 400 µs の速さで動く。昇降を動かす前にヨーを正面へ、ヨーを動かす前に昇降を下へ戻す。
- 1 点で動かせるのは、調整を始めた値から ±250 µs まで。
- 角度調整タブへ移ると、運転を止めて原点へ戻してから始まる。リモコンタブへ戻ると原点へ戻って待機に戻る。保存していない変更があるときは、もう一度押すと破棄して戻る。
- 終了（`systemctl stop`）したときも、原点へ戻してから止まる。
